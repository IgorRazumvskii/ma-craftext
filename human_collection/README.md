# Ручной сбор траекторий easy_train

Изолированный прототип для локального сбора командных траекторий. Для работы нужны файлы среды и CrafText из этой ветки; в `human_collection/` находятся только новые скрипты сбора и зависимости. Никакие чекпоинты MAPPO и GPU не нужны.

## Установка

Нужен Python 3.10 или 3.11, поддерживаемый платформой зависимостей JAX. Из корня рабочего каталога:

```bash
python3.11 -m venv .venv-human
source .venv-human/bin/activate
python -m pip install -r human_collection/requirements.txt
python human_collection/collect.py --list
python human_collection/collect.py --instruction 0 --seed 0
```

Первый запуск среды и каждого шага может занять время из-за компиляции JAX. Зависимости загружаются из PyPI. Потребуется доступ к графическому окружению. Внутри CrafText используется заглушка текстового энкодера: DistilBERT и загрузка весов для игры не нужны; символьное наблюдение сохраняется без этой заглушки.

## Управление

`1`, `2`, `3` или `Tab` — выбрать агента и его локальный вид; стрелки вверх/вниз — выбрать доступное его роли действие; пробел — поставить действие в очередь; Enter — одновременно выполнить действия всех агентов. После шага все действия снова равны `NOOP`. `Esc` или закрытие окна прерывает эпизод без записи.

Показана пиксельная картинка текущего агента, вырезанная штатным рендерером вокруг него. Клетки, скрытые в символьном наблюдении маской освещённости, принудительно затемняются. Панели состояния остаются пиксельными, поэтому они не являются буквальным отображением всех полей символьного вектора. Оператор может переключаться между всеми тремя агентами и, следовательно, имеет совокупную информацию команды; при использовании для обучения отдельных агентов это надо учитывать.

## Данные

Только после подтверждённого штатным CrafText-чекером успеха создаются `human_data/parts/human_<id>.parquet` и `human_data/human_<id>.json`. В Parquet хранятся локальные символьные наблюдения **до** действия, совместные действия, награды, признаки завершения и индексы задачи и инструкции. Формат совместим с компактными наблюдениями существующего `TeachLLM/data/build_mappo_sft.py`. JSON хранит seed, текст, название задачи, хеш сценария, версию кода и источник `human`. Неудачные и незавершённые эпизоды не сохраняются. Идентификатор случайный 31-битный: перед объединением независимых наборов проверяйте отсутствие совпадений.

```bash
python TeachLLM/data/build_mappo_sft.py \
  --parts human_data/parts --mode both --output human_sft
```

Текущие инструкции берутся из `easy_train`, включая парафразы; `--list` показывает все индексы. Чтобы повторить конкретную попытку, нужны тот же seed, индекс инструкции, версия кода и записанная последовательность действий. Автоматическая проверка воспроизведения и сохранение неудачных попыток пока не реализованы. При подборе данных для обучения проверяйте качество эпизодов и выделяйте отдельные seed для оценки.
